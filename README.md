# Software Engineering Portfolio

A personal software engineering portfolio built with **Python** and **Django** to showcase my projects, technical experience, and growth as a developer.

The goal is to build a full-stack application with dynamic project pages, structured content management, and interactive features. 

---

## About the Project

This portfolio will serve as a central place to present my software engineering work, including full-stack applications, AI-powered tools, research projects, and community-focused platforms.

The site will be designed to help recruiters, hiring managers, and other developers quickly understand:

- Who I am as a software engineer
- The technologies I work with
- The problems my projects solve
- My role and contributions to each project
- The technical decisions behind my work
- The real-world impact of the applications I build

---

Projects will be stored and managed through Django models instead of being hard-coded into the website.

- Key features

- Technical decisions
- Screenshots or demonstrations

- Live application link
- Lessons learned
- Future improvements
